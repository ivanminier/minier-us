# Self-hosted typography

Latin WOFF2 subsets from Google Fonts, retrieved 2026-10-27. Each family retains
its upstream SIL Open Font License alongside the files. Only the two content
families selected for a route are linked by Base.astro. Weights 400, 500, 600,
and 700 are available; the browser fetches only used weights. No remote font
service is contacted by visitors.
